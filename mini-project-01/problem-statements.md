## Objective

This mini-project provides you with the opportunity to compile and install a new Ubuntu kernel on your system.

## Instructions

1. Students should form a group of up to 6 – 8 members.
2. Study the process of compiling and installing a new Ubuntu kernel by visiting the following resource: [Ubuntu kernel documentation](https://ubuntu.com/kernel/docs/how-to/develop-customise/build-kernel/)
3. Compile and install the kernel on your machine.

**Hint:** It is recommended to deploy the new kernel in a Linux virtual machine using virtualization software such as VMWare or VirtualBox. This allows you to easily roll back to the previous kernel if your system becomes unstable.

## Submission

Submit a report detailing the step-by-step process of how to compile and install the kernel.
